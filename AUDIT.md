# Audit ledger

What a person has read in this repository, and what is still AI-written and
unread. Git cannot say: every commit is authored by Miguel whoever wrote the
code, so this file is the record.

**Default: every file not listed below is `ai`** — written by AI, not yet
read by a person.

| Status | Meaning |
|---|---|
| `ai` | Written by AI. No person has read it. |
| `reviewed` | A person read the whole file at the commit given. |
| `human` | A person wrote it. |

Only a person changes a Status. A `reviewed` file that changes after its
commit is reported as **stale** by
`Carino-Systems/baseline/check.py --provenance`: a review covers the code
that was read, not later edits.

Not listed and not code to study:

- files whose first line says `generated by Carino-Systems/baseline/apply.py`.
  Their source is the template in Carino-Systems/baseline/templates/;
- the shared files copied in by Carino-Systems/propagate.sh
  (`carino-navbar.js`, `carino-clock.js`, `carino-lang.js`,
  `carino-bridge.js`, `carino-diag.js`, `carino-anim.*`). Review the
  canonical copy named at the top of propagate.sh;
- third-party code: anything under `vendor/`, `node_modules/` or
  `*.min.js`, and self-hosted fonts.
